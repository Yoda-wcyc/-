翻成人話
報告裡的專有名詞都收在這——第一次看先展開對照，把數字背後的意思講白，沒有財經底子也能看懂。
小提醒：所有表格的欄位標題（Ticker／5D%／WtdAlpha…）都可以點一下排序，點第二下反向。
漲跌與強弱指標
1D%
今天單日的漲跌幅（今天漲/跌幾 %，絕對值，不跟大盤比）。
5D% / 1M% / 3M%
近 5 日 / 近 1 個月 / 近 3 個月的漲跌幅（絕對值，用在「新高+新低池」）。
REL5 / REL20 / REL60
相對強度＝這檔近 5 / 20 / 60 日的報酬「減掉大盤」。正＝跑贏大盤、負＝跑輸。短線看 REL5、中線 REL20、長線 REL60。
WtdAlpha（加權 Alpha）
把不同時間長度的強弱加權、綜合成一個「強度分數」，越高＝整體越強。
「量」是什麼？
本報告的「量」＝WtdAlpha 強度分數，不是成交量、成交金額、也不是成交張數。資料源沒有成交量欄位，改用「強度」當「這檔多受資金追捧」的代理——看到「量·強度(WA)」就是在看 WtdAlpha，不是看買賣了多少錢或幾張。
排名與數量
Rank / 20R / 60R / 120R
強度排名，0～100，越大越強（Rank 為綜合、其餘對應各時間窗口）。
N
這個板塊／分類裡有幾檔股票（成員數）。
股票池與分級
🔥3個月新高
❄️3個月新低
創下近 3 個月的新高／新低。02 的池子＝新高（最強）＋新低（最弱）合起來，同時盯兩個極端。
A / B / C 級
三條件（REL5、REL20、REL60 都過門檻）全中＝A 級（最強）；REL5+REL20 過＝B 級；只中一項＝C 級觀察池。
廣度 / 高低比
市場上漲面有多寬。高低比＝新高家數 ÷ 新低家數，越大＝多方越佔上風。
§02 三軸怎麼用（量價綜合）
三個鏡頭
價＝只看純漲跌（5D/1M/3M）；量·強度(WA)＝只看 WtdAlpha 強度（越高越強）；量價綜合＝把強度和漲跌交叉，找同方向（共振）或反方向（背離）的股票。
短 / 中 / 長
同一份清單切三個時間框：短＝近 5 日、中＝近 1 個月、長＝近 3 個月，用來看短中長哪個尺度在動。
量優先 / 價優先
量優先＝先挑 WtdAlpha 強的、再看它漲不漲；價優先＝先挑漲得多的、再看它強度夠不夠。同一批股票、兩種切入角度。
判定邏輯
「量強」＝有站上 3 個月新高（🔥）；「價強」＝該時間框漲跌 >0。兩者交叉出下面三種訊號。
量價綜合訊號
★共振
又創新高、短線又在漲（量強＋價強，同方向，最健康）。
⚠佈局型
有創新高但短線在回檔（量強、價弱，強勢股休息中）。
⚠危險型
還在新低但短線反彈（量弱、價強，弱勢股跳一下，未必轉強）。
⚡當日異動
單日大漲/大跌跨門檻。REL5 同步強＝「起漲·觀察」；REL5 弱＝「脈衝·待確認」（可能只是單日跳動）。
